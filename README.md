# 🔤 Passaparola Oyunu

C# ve Windows Forms ile yazılmış basit bir **Passaparola (kelime bilgi yarışması)** oyunu.
A'dan Z'ye her harf için bir soru soruluyor ve oyuncu cevabı yazarak ilerliyor.

## 🎮 Nasıl Oynanır?
1. **Başla** butonuna tıklayın, ilk soru ekrana gelir.
2. Cevabınızı kutuya yazıp **Enter**'a basın.
3. **Sonraki** butonuyla bir sonraki soruya geçin.

Harf renkleri:
- 🟨 **Sarı:** sıradaki soru
- 🟩 **Yeşil:** doğru cevap
- 🟥 **Kırmızı:** yanlış cevap

Doğru ve yanlış sayıları ekranda anlık olarak gösterilir.

## 🛠️ Kullanılan Teknolojiler
- C#
- Windows Forms (.NET Framework)
- Visual Studio

## ▶️ Çalıştırma
1. Projeyi indirin veya klonlayın.
2. `.sln` dosyasını Visual Studio ile açın.
3. **Start** butonuna basarak çalıştırın.

## 📚 Öğrendiklerim
- Windows Forms'ta buton, TextBox, RichTextBox ve LinkLabel kullanımı
- `KeyDown` ve `LinkClicked` olaylarıyla çalışma
- `switch-case` ve `if` yapıları
- Kontrollerin renklerini kod içinden değiştirme
